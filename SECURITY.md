# Security Policy

## Authorized Use Only

n3rve is a WPA/WPA2 passphrase recovery tool intended for:

- Authorized penetration testing engagements
- Security assessments on networks you own or have written permission to test
- Educational laboratory environments

## Unauthorized Use Is Prohibited

Do not use n3rve to access wireless networks without explicit authorization. Unauthorized access to computer networks is illegal in most jurisdictions and may result in criminal penalties.

## Vulnerability Reporting

If you discover a security vulnerability in n3rve itself (not in the networks it is tested against), please report it responsibly:

- Open a private issue or contact the maintainer directly
- Do not disclose the vulnerability publicly until it has been addressed
- Include steps to reproduce, affected versions, and potential impact

## No Liability

The author and contributors assume no liability for misuse of this software. Users are solely responsible for ensuring their use complies with all applicable laws and regulations.

## Scope

This policy applies to the n3rve software repository only. It does not authorize testing of any specific network, organization, or system.
